## How-To

### 1. Setup Server

1. Install Python 3.12 and add `python.exe` to path.

2. Run `setup.cmd`.

### 2. Run Server

1. Run `start-dev.cmd`.

### 3. Start Game

1. Use a game launcher to start the game, preferably OpenBachelor Client.
